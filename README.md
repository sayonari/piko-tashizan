# ピコピコたしざん 🟧🟦

4さいから あそべる、**2けたの たしざん** を「10のぼう」と「1のつぶ」で目で見て体で覚えるレトロゲーム。
iPhone / iPad の Safari でそのまま遊べます（インストール不要・オフライン対応）。

▶ **あそぶ: https://sayonari.github.io/piko-tashizan/**

姉妹作: [ピコピコかけざん](https://sayonari.github.io/piko-kakezan/)（九九）

## あそびかた
1. 上に `23+14=?` のような問題が出て、盤面に **オレンジの10のぼう** と **青い1のつぶ** が並びます
   - 左の列 = 10のくらい（ぼう）、右の列 = 1のくらい（つぶ）… そろばん・筆算と同じ並び
   - 数字の色も「10のくらい＝オレンジ」「1のくらい＝青」で統一
2. **「がったい!」** を押すと下の段が上の段に合体
   - つぶが **10こ** 集まると、ピカッと光って **ぼう1ぽん** に変身して10のくらいへジャンプ（くりあがり）
   - 下の段に「4+2」「3+3」のように、たての列ごとの計算が出ます（1けたの足し算の組み合わせ）
3. 3つの答えから選んでタッチ。正解で花火と★、まちがえてもヒントで合体してくれます
4. 10問で ステージクリア！ ぜんぶ1回で正解すると 👑

| ステージ | 内容 | れい |
|---|---|---|
| 1 | 10と いくつ | 30+4 |
| 2 | 2けた + 1けた | 23+4 |
| 3 | 2けた + なんじゅう | 23+30 |
| 4 | 2けた + 2けた | 23+14 |
| 5 | くりあがり（2けた+1けた） | 27+5 |
| 6 | くりあがり（2けた+2けた） | 38+25 |
| 7 | ぜんぶ ミックス | |
| 🌈 | のうじるモード | コンボで脳汁！ |

答えは99まで。音声読み上げ（「23 たす 14 は?」）・効果音・BGMは選択画面右上でON/OFFできます。

## メニュー（4つの へや）
さいしょの画面は、4さいでも えらべるように ★の数とアイコンで 分けています。
| へや | 中身 |
|---|---|
| ★ やさしい | きほんの れんしゅう |
| ★★ ふつう | すこし むずかしい れんしゅう |
| ★★★ むずかしい | しあげの れんしゅう |
| 🎮 ゲームで あそぶ | のうじるモード・はやおしバトル・じっくりバトル |

## ⚔️ たいせんモード（てき: スライム → コウモリ → おばけ → ロボット → ドラゴン → つよい○○ …）
- **⚡ はやおしバトル**: おなじ問題を てきと 早押し。てきの「かんがえちゅう…」ゲージが たまる前に正解すると こうげき！ 先に答えられると ハートが へる。まちがえるとゲージが進む
- **⚔️ じっくりバトル**（ターンせい）: 自分の番に **こうげき / かいふく / ひっさつ** をえらび、問題に正解すると成功（はやく正解すると「かいしんの いちげき」）。
  ひっさつは正解3回でたまる★を使う、むずかしい問題で大ダメージ。てきの番は「けいさんで まもれ!」→ 正解でガード。
  てきが「ちからを ためている!」ときは強いこうげきが来るので、かいふくするか考えよう
- 勝つと「つぎの てき」でレベルアップ。たおしたレベルは記録されます
- 対戦の仕組みは `battle.js`、メニューは `menu.js`（ピコピコたしざん／かけざん共通）

## 🌈🔥 のうじるモード
コンボがつながるほど気持ちよくなる、ド派手なタイムアタック（40秒スタート）。
- 正解するたびに **レインボーの爆発・衝撃波・画面フラッシュ**、コンボが上がるほど効果音の音程がどんどん上がる
- 5コンボごとに点数の倍率アップ（×2, ×3 …）、正解で **+4びょう**、まちがえると **-3びょう** でコンボがとぎれる
- **10コンボで「フィーバー!!」**：画面全体がレインボーに回転、BGMがスピードアップ（20コンボ「すごすぎ!!」30コンボ「かみ!!!」）
- 演出は `fever.js`（ピコピコかけざんと共通）

## iPhone / iPad で遊ぶ
1. Safari で公開URLを開く
2. 共有ボタン →「ホーム画面に追加」でアプリのように全画面で遊べます
3. マナーモードでも音が出ます（Safari 16.4 以降）

## 技術メモ
- `index.html` 1ファイル（Canvas + WebAudio のチップチューン合成 + SpeechSynthesis）。外部依存は Google Fonts の DotGothic16 のみ
- `sw.js` でオフラインキャッシュ、`manifest.webmanifest` でホーム画面アプリ化
- 進行状況は端末の localStorage に保存
- アイコン再生成: `uv run --with pillow make_icons.py`
- ローカル確認: `python3 -m http.server 8765` → http://localhost:8765/
